# Radio Crestin 1.6.1

**Status:** not released yet · **Changes since:** [1.6.0](v1.6.0.md) (November 4, 2026) \
**Platforms:** iPhone, iPad, Android, Android TV, Apple TV, Mac, Windows, CarPlay, Android Auto

<!-- say: Radio Crestin version one point six point one keeps the radio playing when the connection is weak or drops for a moment. -->

A follow-up to 1.6.0: the radio keeps playing when the connection is slow or drops for a moment.

## Fixes

<!-- say: On a slow connection, iPhone now waits for the station to load instead of starting it over and over. A station whose stream drops for a moment now comes back by itself, instead of stopping. -->

- **On a slow connection, iPhone plays the station** instead of starting it over every few seconds: it now
  waits while the audio is still arriving.
- **A station whose stream drops for a moment comes back by itself.** Stations that stream MP3 used to stop
  and show an error when their connection ended (a server restart, a network blip); they now reconnect, as
  the others always did.

## Under the hood

<!-- slides: skip -->

For developers; nothing here changes what listeners see.

- The e2e suite (`integration_test/`) runs the real app against a fake radio server and a network that
  slows, stalls, drops and goes offline; it found both fixes above.
